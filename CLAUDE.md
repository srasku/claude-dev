# Project Instructions

## Project Context

- When you first explore this codebase, document what you find here: purpose of
  the project, build/run commands, source layout, key design decisions, and
  anything else a future session would need to get up to speed without asking.
  Keep this section updated as the project evolves.

## User Setup

- Claude is running in a container.  The human developer can install required
  software in the container.  Don't hesitate to ask.

## Plan Mode Workflow

- Before making significant revisions to an existing plan file, rename the old
  plan first (e.g. `mv clever-seeking-lighthouse.md prev-clever-seeking-lighthouse.md`)
  so the user can diff the two versions.
